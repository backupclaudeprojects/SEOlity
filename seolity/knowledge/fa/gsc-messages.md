# پیام‌ها و ایمیل‌های سرچ کنسول

گوگل برای پیام‌های سرچ کنسول API ندارد. پیام‌ها در بخش «Messages» (آیکون زنگ) و در ایمیل مالکان و کاربران ملک (property) دیده می‌شوند. متن پیام را در SEOlity → «پوشش ایندکس» بچسبانید تا با داده سایت تطبیق داده شود و توضیح و برنامه اقدام بگیرد. SEOlity با بررسی روزانه URL Inspection بیشتر این مشکلات را خودش هم پیدا می‌کند.

## پیام‌های ایندکس
### «New reasons prevent pages in a sitemap from being indexed»
یک دلیل جدید باعث شده آدرس‌هایی از نقشه سایت ایندکس نشوند، مثلاً Redirect error یا Server error. **اقدام:** روی دلیل در گزارش Pages کلیک کنید، خروجی آدرس‌ها را بگیرید و بررسی کنید آدرس عمدی است یا صفحه واقعی. سند «راهنمای کامل گزارش Page indexing» را ببینید. اهمیت به **تعداد** و **ارزش** صفحه‌ها بستگی دارد. یک آدرس قدیمی کم‌اهمیت است، ده‌ها محصول مهم.

### «Page indexing issues detected» / «New Page indexing issue»
مشابه پیام قبلی، برای کل سایت (نه فقط نقشه سایت).

### خطای نقشه سایت («Sitemap could not be read» و مانند این)
گوگل نتوانسته نقشه سایت را بخواند: آدرس اشتباه، خطای سرور، حجم بیش از حد (بالای ۵۰ هزار آدرس یا ۵۰ مگابایت) یا XML نامعتبر. **اقدام:** آدرس نقشه را در مرورگر باز کنید، خطا را در سرچ کنسول ← Sitemaps ببینید و دوباره ثبت کنید.

## پیام‌های تجربه کاربری
### Core Web Vitals
گروهی از صفحه‌ها برای کاربران واقعی (داده Chrome) کند یا ناپایدارند. اختلال در LCP، INP یا CLS. **اقدام:** گروه آدرس‌ها را ببینید، معمولاً همه از یک قالب‌اند (مثلاً همه مقاله‌ها). همان قالب را بهینه کنید: کش، تصاویر و اسکریپت‌ها. بعد Validate fix بزنید. اثر روی رتبه متوسط است، ولی روی تبدیل زیاد.

### HTTPS
آدرس‌هایی روی http سرو می‌شوند یا گواهی مشکل دارد. **اقدام:** ریدایرکت کامل به https و تمدید گواهی.

## پیام‌های داده ساختاریافته
مثل «Product snippets issues»، «Merchant listings»، «Breadcrumbs»، «FAQ» و «Review snippets». بخشی از اسکیما نامعتبر یا ناقص است. **اقدام:** آدرس نمونه را در Rich Results Test بررسی کنید و فیلد گمشده را تکمیل کنید (مثلاً `priceCurrency`، `availability` و `review`). در ایران رایج‌ترین خطا واحد پول است: باید `IRR` باشد و مقدار به ریال.

## پیام‌های جدی
### Manual action (اقدام دستی)
یک بازبین گوگل سایت را به دلیل نقض دستورالعمل جریمه کرده است: لینک غیرطبیعی، محتوای اسپم یا داده ساختاریافته گمراه‌کننده. **جدی‌ترین پیام است.** **اقدام:** در Security & Manual actions جزئیات را بخوانید، همه موارد را اصلاح کنید، مستند کنید و Request review بفرستید.

### Security issues (مشکل امنیتی)
سایت هک شده، بدافزار دارد یا فریب‌کاری (phishing) در آن تشخیص داده شده است. **اقدام فوری:** پاک‌سازی فایل‌ها و دیتابیس، تغییر رمزها، به‌روزرسانی وردپرس و افزونه‌ها، بررسی کاربران ادمین، و بعد Request review.

## پیام‌های مدیریتی
- **New owner / New user:** کسی به ملک دسترسی گرفته است. اگر خودتان نبوده‌اید، فوراً بررسی و دسترسی را حذف کنید.
- **Performance milestones:** کلیک‌ها به رکورد تازه رسیده است. خبر خوبی است و اقدامی لازم ندارد.
